# Учимся считать с роботом! Цифры от 1 до 10

Детский образовательный мультфильм (ровно 3 минуты) с оригинальным роботом **Бип**.

## Результат

Финальный файл:

`project/output/robot_counting_1_to_10.mp4`

- 1920×1080, 30 FPS, 180 секунд, 5400 кадров
- H.264 / yuv420p, без аудио, faststart
- Русские надписи, без озвучки и музыки

## Запуск производства

```bash
cd project
npm install
npm run all
```

Подробности — в `project/README.md`.
